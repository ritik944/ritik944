## 💼 Experience

### 🏥 Piramal Swasthya (Piramal Foundation): Python Data Analyst, Applied AI
*Sep 2025 – Present · Raipur, India*

- **Conversational analytics assistant:** a production RAG assistant (LangGraph + Gemini) that turns plain-English questions from health officials into SQL-backed charts and insights in seconds.
- **Retrieval pipeline:** ChromaDB embeddings with top-K KPI retrieval, measured against an internal query evaluation set.
- **Dashboard-builder framework:** agentic code generation with Claude Code, now the standard build workflow for the analytics team.
- **Demand forecasting (leading):** time-series forecasting of medical supply consumption across facilities, feeding a scheduling layer that replaces manual monthly distribution planning.
- **Scaled Apache Superset** from one node to a multi-server deployment with load-balanced web workers, Redis caching and Celery async query workers on Ubuntu and Docker.
- **Security layer:** a Flask auth server issues JWTs to a FastAPI microservice, and Superset guest tokens enforce row-level security across 5 hierarchical roles (national → facility).
- **ETL pipelines:** automated Excel ingestion via the Microsoft Graph API, MS Forms ingestion, and a MySQL → PostgreSQL migration.
